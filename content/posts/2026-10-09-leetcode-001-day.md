# Python 算法学习笔记总结

## 一、Python 基础与常用技巧

### 1. 列表 vs 元组
| 特性 | 列表 `list` | 元组 `tuple` |
|------|------------|--------------|
| 可变性 | 可修改 | 不可修改 |
| 内存 | 较大 | 较小 |
| 速度 | 创建稍慢 | 创建快 |
| 哈希 | 不可哈希 | 可哈希（可作字典键） |
| 场景 | 动态增删、算法题 | 常量、字典键、数据库返回 |

**结论**：算法题多用列表（需动态修改），工程中元组用于只读数据。

### 2. 集合 `set` 与 `frozenset`
- `set`：可变，去重、O(1) 查找。
- `frozenset`：不可变，可哈希，能作字典键或嵌套集合。
- 常用操作：`add`、`remove`、`in`、`&`、`|`、`-`。

### 3. 字典 `dict` 常用操作
- 安全取值：`d.get(key, default)`
- 判断键：`key in d`
- 遍历：`for k, v in d.items()`
- 计数：`d[key] = d.get(key, 0) + 1`
- `defaultdict(int)`、`Counter` 简化计数。

### 4. 字符串
- **不可变**：不能 `s[i] = 'x'`，需转列表或切片。
- 反转：`s[::-1]`
- 大写：`s.upper()`、`s.lower()`
- 判断：`s.isupper()`、`s.isdigit()`
- 补零：`s.zfill(4)`
- 字符与 ASCII：`ord(c)`、`chr(n)`
- 数字转字符：`str(1)` → `'1'`

### 5. 常用内置函数与模块
| 功能 | 方法 |
|------|------|
| 排序 | `nums.sort()`（原地）、`sorted(nums)`（新列表） |
| 求和 | `sum(nums)` |
| 最大最小 | `max()`、`min()` |
| 计数 | `Counter`、`collections.defaultdict` |
| 双端队列 | `collections.deque`，`popleft()`/`pop()` |
| 累积 | `functools.reduce` + `operator` |
| 最大公约数 | `math.gcd(a, b)` |
| 缓存 | `functools.lru_cache`、`cache` |
| 整数二进制 1 个数 | `n.bit_count()` |

### 6. 装饰器
- 作用：不修改原函数，增强功能（计时、日志、缓存等）。
- 模板：
```python
from functools import wraps
def decorator(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        # 前置
        res = func(*args, **kwargs)
        # 后置
        return res
    return wrapper
